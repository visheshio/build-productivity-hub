## 🆘 Troubleshooting

### Not loading?
```bash
npm run dev
# Wait for build to complete
# Visit http://localhost:5173
```

### Theme not changing?
- Refresh page (Cmd+R)
- Clear localStorage if needed
- Try different theme

### Data not saving?
- Check browser localStorage is enabled
- Try incognito mode
- Refresh page

### Performance slow?
- Check browser console for errors
- Clear browser cache
- Restart dev server
